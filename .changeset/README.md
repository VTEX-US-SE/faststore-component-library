# Changesets

Cada paquete de este monorepo versiona de forma independiente (semver por paquete).

Al hacer un cambio que deba publicarse, correr:

```bash
pnpm changeset
```

y seguir el prompt para elegir los paquetes afectados y el tipo de bump (patch/minor/major).

Ver la documentación completa en https://github.com/changesets/changesets
